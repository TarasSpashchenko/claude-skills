# Frequent errors

This list gives words that agents frequently write in technical text but that are not approved in the STE dictionary (lowercase entries). The dictionary is the authority: before you select an alternative, read the full entry on the given page. A script must never replace these words automatically: the writer selects the alternative that keeps the meaning, or writes a different sentence construction (rule 9.1).

Some words of this list are also example technical verbs of rule 1.12 (pages 57 and 58): "copy" is a computer process (category 2), and "modify" and "omit" are verbs for specifications (category 4). Use them only for that process, only as a verb, and only when no approved verb gives the same meaning. A project can accept a category with `verb_categories` in `.ste.toml`, or register a verb such as "run" (for a computer process) in `terms.verbs`.
