# Components

## Overview

One folder per component under `src/components/`.

| Part | What it holds | Start here |
|---|---|---|
| `src/components/button/Button.tsx` | the button | `Button` |

## Rules

- Every component folder exposes an `index.ts`; import from the folder (`@/components/Button`).
- `Button` takes `variant`: `primary`, `secondary` or `ghost`.
